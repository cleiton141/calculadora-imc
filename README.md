# Calculadora IMC com Histórico

## sobre o Projeto
Calculadora de IMC completa com:
Tabela de referência da OMS
Destaque em tempo real
Histórico com nome do usuário
Armazenamento local

## como Usar
1. Digite seu nome
2. Informe peso (kg) e altura (m)
3. Clique em calcular
4. Veja o resultado e a tabela destacada

## tecnologias
- HTML5
- CSS3
- JavaScript ES6
- LocalStorage API
